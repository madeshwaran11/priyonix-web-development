# PriyoniX 3D Animated Landing Page

A responsive one-page marketing website for the PriyoniX Web Development service.

## Included
- PriyoniX logo supplied for the project
- Dark blue + light blue visual theme
- CSS 3D website mockup and rotating cube
- Mouse-follow 3D tilt interactions
- Floating chips and orbit animations
- Scroll reveal animations
- Responsive mobile navigation
- Hero, service, benefits, why-us, sample outcomes, process, CTA and lead form
- SEO title, meta description, H1/H2 structure, canonical and Open Graph metadata
- Image alt text
- Reduced-motion accessibility support
- Demo lead form ready to connect to a real endpoint

## Run locally

```bash
python -m http.server 8080
```

Open:

http://localhost:8080

## Deploy

Upload the project to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or AWS S3 + CloudFront.

Before production:
1. Replace `https://example.com/` with the real staging/production URL.
2. Connect the lead form to the company's email/CRM/backend.
3. Replace the sample design-principle statement with a verified customer testimonial if available.
4. Run Lighthouse/PageSpeed.
5. Check all links and the form on desktop and mobile.

## Performance note

The 3D effects are CSS/JavaScript based and do not require a 3D library. Animations automatically reduce when the visitor has enabled `prefers-reduced-motion`.
